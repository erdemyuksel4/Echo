# Plan for Implementing Differential Updates (Phase 6)

## Goal
Enable Electron Builder to generate and publish a **delta package** for Windows NSIS installers so that the updater downloads only the changed parts instead of the full ~84 MB installer.

## Files to Modify
- `apps/desktop/package.json` – add `nsisWeb` configuration with `differentialPackage: true` and ensure the `publish` settings include the generated `.exe.delta` artifact.
- `scripts/bump-version.mjs` – extend the upload logic to also upload the `.exe.delta` file generated by Electron Builder.

## Risks & Mitigations
- **Delta package not generated**: Verify the `nsisWeb` option is correctly placed under the `build` section; run a test build and confirm the existence of `Echo-Setup-<ver>.exe.delta`.
- **Updater fails to apply delta**: Ensure the `latest.yml` lists the delta artifact with correct `url` and `sha512`. Test the update flow from version 0.1.44 to 0.1.45.
- **Release script omission**: Update `scripts/bump-version.mjs` to include the delta file in the `filesToUpload` array; otherwise the file won't be published.

## Test Procedure
1. Build version 0.1.44 (existing installer) and install it.
2. Run `pnpm release` to produce version 0.1.45 with the new configuration.
3. Verify `dist` contains `Echo-Setup-0.1.45.exe.delta` and that `latest.yml` references it.
4. Launch the installed 0.1.44 app and trigger the updater (IPC `updater:check`).
5. Observe that the download size reported is significantly smaller (expected < 10 MB).
6. Ensure the app updates successfully and runs without errors.

## Acceptance Criteria
- The GitHub release for 0.1.45 includes both the full installer and the delta (`.exe.delta`).
- `latest.yml` lists the delta artifact.
- Updating from 0.1.44 downloads only the delta and completes successfully.
- All tests (`pnpm typecheck`, `pnpm lint`, `pnpm test`) pass.
